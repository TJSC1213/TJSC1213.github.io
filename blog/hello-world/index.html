随想 开始

每个博客的第一篇都是最难的：既想写得漂亮，又想写得诚实。这篇尽量只做到后者。

为什么又开始写了

过去几年里，我解决过的问题大多散落在聊天记录、临时笔记和被遗忘的浏览器标签里。等到第二次遇到同一个坑时，我几乎要从零开始回忆一遍。写下来，是最省事的一种保险。

另一个原因是：写清楚一件事，往往比做完它更能暴露理解上的漏洞。很多时候我以为自己懂了，直到要把它讲给别人听。

这里会写什么

  • 踩坑记录： 报错信息、排查过程、最后那个其实很蠢的根因。
  • 工具折腾： 编辑器、命令行、自动化脚本 —— 任何让我少点几下鼠标的东西。
  • 读后随想： 书和文章里那些让我坐不住的论点。

判断一个博客是否值得写下去的标准很简单：如果明天服务器全挂了，你还会想继续写吗？

这个站是怎么做的

没有用任何静态站点生成器，也没有引入框架或 CDN：整个站就是几个手写的 HTML 文件加上一份 CSS 和三个小脚本，托管在 GitHub Pages 上。中英双语切换靠元素属性驱动，代码高亮是一个自己写的小脚本。

具体做法写在下一篇： 《用纯 HTML/CSS/JS 做一个中英双语静态博客》。
